# Phan Quốc Tuấn

### Flutter & Mobile Developer

I build Flutter applications with a focus on clear UI, structured state management, and API integration. My public projects cover healthcare appointment booking, quiz and collaboration features, e-commerce, and weather data.

## Technical focus

- **Mobile:** Flutter, Dart, BLoC / Cubit
- **Application structure:** presentation, domain, and data layers; repository and use-case patterns; dependency injection with GetIt
- **Data & services:** REST APIs, Firebase Authentication, Cloud Firestore, local storage with SharedPreferences
- **Web experiments:** React, JavaScript, Three.js, React Three Fiber

## How I approach development

- Separate UI, business logic, and data access to keep features easier to navigate and maintain.
- Use BLoC / Cubit for explicit state management in Flutter applications.
- Connect app features to APIs and local persistence around concrete user flows.
